# pokemon-cards-css

このディレクトリの CSS は [simeydotme/pokemon-cards-css](https://github.com/simeydotme/pokemon-cards-css)
（Copyright (C) 2022 Simon Goellner、GPL-3.0）から取り込み、次の変更を加えたもの。

- `.card` / `.card__*` を、他のスタイルと衝突しないよう `.holo-card` / `.holo-card__*` に置き換えた
- `cards.css` はテクスチャのパスを `/stamp-rally/glitter.png` に変更し、使わない `grain` を外した
- エフェクトは「rare rainbow alt」(`rainbow-alt.css`) のみ使用
