# CMS 当日更新マニュアル

茨香祭の当日に、開催時間・中止情報・お知らせなどを変更するときの手順です。編集内容は公開ページに表示されるため、現地の責任者と内容を確認してから保存してください。

## まず確認すること

- CMS: [https://34.shikosai.net/admin/](https://34.shikosai.net/admin/)
- CMS は Cloudflare Access で保護されています。許可されたアカウントで認証してください。CMS 用の GitHub ログインは不要です。
- 保存すると、設定上は `main` ブランチに直接コミットされます。下書きの確認依頼や承認待ちの仕組みはありません。
- 保存完了は、公開ページへの反映完了を意味しません。公開ページを開いて変更を確認するまで、来場者へ反映済みと案内しないでください。
- 変更する前に、対象ページの現在の表示と、変更内容の根拠（現地責任者の確認）を記録します。

## 当日の時間変更・中止を掲載する

### ステージ企画

1. CMS 左側の **ステージ企画** を開き、対象企画を出演団体名・企画名・開始時刻で探します。
2. 企画を開き、**開始日時**と**終了日時**を開催日（2026年10月24日または25日）の日本時間で更新します。開始・終了が同じ日で、終了が開始より後になっていることを確認します。
3. 時間が変わった企画は **当日の状態** を「時間変更あり」にします。中止は「中止」にします。予定どおりに戻った場合は「予定どおり」に戻します。
4. 必要なら **短い説明** または **詳細** に補足を書きます。個人名・電話番号など、公開してよいと確認できていない情報は書かないでください。
5. **下書き** がオンだと本番サイトに出ません。公開する変更ではオフであることを確認します。
6. 保存し、一覧で対象企画と日時・状態を再確認します。

一覧には「時間変更あり」「中止」などの絞り込みがあります。ステージ企画は開始日時順に `/event` と `/timetable` に掲載されます。

### サークル・お知らせ

- **サークル**: 対象団体を開き、**実施時間（10月24日／10月25日）**、**実施場所**、必要に応じて **雨天時の場所・対応** を更新します。実施しない日の時間欄は空欄にします。
- **お知らせ**: 新しい告知は **お知らせ** から作成します。タイトル、公開日時、要約、本文を確認し、公開する場合は **下書き** をオフにします。既存のお知らせは編集して更新日時も設定してください。
- 来場者への影響が大きい変更は、公開後に対象ページと `/news` の両方を確認します。

## CMS の基本操作

### 既存内容を編集する

1. 左側で **お知らせ／サークル／ステージ企画／協賛企業／実行委員の部署紹介** のいずれかを選びます。
2. 一覧から対象を選びます。候補が多い場合は一覧の並び替え・絞り込みを使います。
3. 変更する項目だけを編集し、入力欄の説明（ヒント）に従います。
4. 保存前に、日付・時刻・公開状態・画像・URL・文章を読み返します。
5. **保存** し、CMS の一覧で編集結果を確認します。

### 新しい項目を追加する

各コレクションの **新規作成** から追加します。必須欄を埋め、URL 識別子（slug）は半角英小文字・数字・ハイフンで設定してください。公開後に slug を変えるとページ URL が変わるため、誤りに気づいた場合は、変更前に責任者と影響を確認します。

### 項目を削除する

削除はページの公開内容を直接なくす操作です。通常は削除せず、ステージ企画なら「中止」、お知らせ・協賛企業など下書き欄がある項目なら下書きにする方法で対応できないか確認します。サークルなど下書き欄がない項目は、削除せず責任者に相談してください。削除が必要な場合は、対象を別の担当者と照合してから実行し、公開ページから消えたことも確認してください。

## 画像の扱い

- **見出し画像・写真欄**: 画像欄からアップロードします。JPEG / PNG / WebP / GIF / HEIC / HEIF / AVIF を受け付けます。最大 15 MB で、長辺 1920 px 以下の WebP に変換して画像ストレージへ保存されます。変換できない形式・画像はエラーになります。
- **本文中の画像**: Markdown 本文の画像ボタンから追加します。本文画像はリポジトリの `public/uploads` に保存されます。見出し画像欄とは保存先が異なります。
- 画像の向き・内容・公開許可を確認してから使用します。アップロードしたあとに編集を取り消しても、画像ファイル自体がストレージに残る場合があります。不要な画像を別の画面から削除しようとせず、運営責任者へ連絡してください。

## 公開反映の確認

1. CMS の保存が完了したことを確認します。
2. 公開サイトで対象のページを再読み込みし、変更が表示されるか確認します。ステージ企画は `/event` と `/timetable`、サークルは `/circle` と対象詳細、お知らせは `/news` と対象記事を確認します。
3. 反映されていない場合は、CMS の一覧で保存状態を確認し、GitHub リポジトリの `main` に該当コミットがあるか、Cloudflare のビルド・デプロイが完了しているかを運用担当に確認します。未反映のまま同じ内容を何度も保存しないでください。
4. 反映確認後、変更内容・確認時刻・確認した公開 URL を当日の運営記録に残します。

## 困ったとき

- **ログインできない／401 と表示される**: Access の許可対象アカウントか確認し、ページを再読み込みします。解決しない場合はCMS管理担当へ連絡します。認証情報をチャットや運営記録に貼らないでください。
- **保存できない／エラーになる**: 画面のエラーと対象項目を記録し、入力内容を別の場所に控えてCMS管理担当へ連絡します。連続して保存を繰り返さないでください。
- **画像をアップロードできない**: 対応形式と15 MB以下であることを確認します。再試行しても失敗する場合は、テキスト変更と分けて画像の問題として担当者へ連絡します。
- **誤った情報を公開した**: すぐに責任者へ共有し、正しい内容へ修正します。公開ページで修正後の表示を確認するまで、訂正済みとしないでください。

## CMS で編集できる範囲

CMS では、お知らせ、サークル、ステージ企画、協賛企業、実行委員の部署紹介を編集します。スタッフページにある代表者・実行委員長などの固定挨拶文は CMS の編集対象ではありません。
