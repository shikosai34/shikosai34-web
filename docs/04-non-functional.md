## 4.1 パフォーマンス

公開前に Lighthouse（モバイル）で計測し、極端に遅い箇所がないことを確認する。**数値目標は設けない。** 目標値を定めても、計測と改善を担当する者と期限が決まっていなければ守られないため。

**留意点:** 暗い背景に発光表現を重ねる意匠は、`box-shadow` や `filter` の多用により描画負荷が上がりやすい。装飾の適用範囲を限定する。また `/map` の会場マップは画像サイズが大きくなりやすいため、個別に転送量を確認する。

## 4.2 アクセシビリティ

**次の4項目を必須とする。** いずれも実装時の判断で対応でき、満たさない場合に実害がある。

| 項目 | 要件 |
| --- | --- |
| コントラスト比 | 第3.2.1節の検証結果に従う。使用不可の組み合わせを用いない |
| 代替テキスト | すべての意味のある画像に設定する。装飾目的の画像は `alt=""` とする |
| 言語指定 | `<html lang="ja">` |
| 点滅の制限 | **1秒間に3回を超える点滅を用いない** |

**点滅の制限について:** 「サイバーパンク」の表現として明滅するアニメーションを用いる場合、光感受性発作を誘発する可能性がある。これは閲覧者の健康に関わるため、他の項目と異なり例外を認めない。

次の項目は必須としないが、対応できる範囲で満たす。

- キーボード操作: 対話要素をキーボードで操作でき、フォーカス位置を視認できる
- 見出し構造: `h1` から順に階層を飛ばさずに構成する
- 色以外の手掛かり: リンク・状態を色のみで区別しない（第3.2.2節の4により、リンクは下線を併用する）
- 動きの制御: `prefers-reduced-motion` を尊重し、アニメーションを抑制する
- 会場マップ: 画像のみで情報を提供せず、テキストによる配置一覧を併記する

**WCAG 2.1 レベル AA への適合は目標とするが、達成を約束しない。** 全項目の検証には相応の作業量を要するため、必須4項目を確実に満たすことを優先する。

## 4.3 対応環境

| 分類 | 対応範囲 |
| --- | --- |
| ブラウザ | Chrome、Safari、Edge、Firefox の各最新版および1つ前のメジャー版 |
| OS | iOS 16以降、Android 11以降、Windows 10以降、macOS 12以降 |
| 画面幅 | 320px 〜 1920px |
| JavaScript 無効時 | 主要な情報（開催日時、サークル一覧、タイムテーブル）を閲覧できる |

Internet Explorer には対応しない。

## 4.4 SEO

**SNS での共有時の表示のみを対象とする。** 年に2日間のイベントであり、来場者は「茨香祭」での検索か SNS のリンクから到達する。検索順位の最適化に作業を割かない。

| 項目 | 要件 |
| --- | --- |
| タイトルタグ | ページごとに固有の文言を設定する |
| OGP | `og:title` / `og:description` / `og:image` / `og:url` を設定する。**画像は開催情報が読み取れるものにする** |

`sitemap.xml`（`@astrojs/sitemap`）、`robots.txt`、`canonical` は初期設定として導入するが、内容の検討は行わない。構造化データ（`schema.org/Event`）は実施しない。

## 4.5 セキュリティ・個人情報

**運用として守るべき事項:**

- **サークル紹介文に個人名・連絡先が含まれないよう、原稿収集時に確認する**
- **API キー等をリポジトリにコミットしない**
- HP 自体はサイト上で個人情報を収集しない。フォームを設置しない

**実装時の設定:**

- 通信は HTTPS のみ。HTTP からリダイレクトする（Cloudflare の既定）
- 外部リンクに `rel="noopener noreferrer"` を付与する

セキュリティヘッダ（`Content-Security-Policy` 等）は、判断に専門的な知識を要するため本文書では規定しない。導入する場合は経験のある者に相談する。

**FesFlow への遷移について:** FesFlow はニックネームと誕生日を収集する構想である。HP から遷移する箇所で説明が必要かは FesFlow 側と調整する ［要検討］。

## 4.6 可用性・運用

| 項目 | 要件 |
| --- | --- |
| 想定アクセス集中期 | 開催1週間前から開催当日まで |
| ホスティング | Cloudflare（CDN によりアクセス集中に対応する） |
| 公開後の更新 | main ブランチへのマージで自動デプロイする |
| FesFlow 障害時の挙動 | HP は静的サイトのため FesFlow の停止に影響されない。ただしリンク先が利用できない状態になる |
| 公開終了後の扱い | 開催後も一定期間公開を継続する。期間は ［未定］ |

監視は実施しない。静的サイトであり、Cloudflare の停止以外に HP 単独で発生する障害がないため。
