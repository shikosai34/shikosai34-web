# `02-overview.md`

## 共通事項

### ヘッダー

現段階ではハンバーガーメニューのみ。

### フッター

掲載するリンクは以下の通りである。

- 公式SNS
  - X (Twitter)
  - Instagram
  - note
- サークル
  - 学年ごとに見る
  - 区分ごとに見る
  - 場所ごとに見る
- イベント
  - 1日目（10月24日（土））
  - 2日目（10月25日（日））
- その他のページ
  - スタッフ
  - アクセス
  - プライバシーポリシー
  - お問い合わせ

## `/`：トップページ

掲載事項は以下のとおりである。

- 茨香祭速報：第33回と同様の形式で広報用ポスターを添付する
- This year's theme：今年の茨香祭のテーマの紹介（ざっくり）
- News：最新のお知らせ

## `/hamburger`：ハンバーガーメニュー

モバイルUIにおけるハンバーガーメニューには以下の内容を記載する。

- `/`：トップページ
- `/circle`：サークル紹介ページ
- `/timetable`：イベント企画・音楽ステージのタイムテーブル
- `/map`：全体の会場地図
- `fesflow`：アカウントページへの動線
- `/sitemap`：サイト全体の一覧
