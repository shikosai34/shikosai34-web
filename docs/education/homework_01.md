# 自己ポートフォリオ制作 課題要件

## 目的

HTML / CSS / JavaScript を使ったフロントエンドの基礎を、実際に手を動かしながら習得する。

## 成果物の要件

| 項目 | 内容 |
|------|------|
| 使用技術 | HTML・CSS・JavaScript（フレームワーク不問） |
| 内容 | 自分自身のポートフォリオサイト |
| 公開方法 | 何らかのサービスにデプロイし、URLで閲覧できる状態にする |
| 期限 | 1ヶ月程度 |

## 制約・ルール

- AI の使用は可（ただし、生成されたコードを理解した上で使うこと）
- フレームワーク・ライブラリの使用可否など、追加ルールは必要に応じて設定

## 未決事項（要確認）

- **提出形式・デプロイ先の指定**：GitHub Pages 限定か、Vercel 等も可か
- **最低限の掲載内容**：品質のばらつきを防ぐため、必須セクションを定義する（例：自己紹介・制作物・連絡先）
- **AI 使用時の理解確認方法**：コードレビュー、口頭説明など
